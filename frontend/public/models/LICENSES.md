# Open-Source Model Licenses and Attribution

This directory contains pre-trained deep learning models from the official [OpenCV Zoo](https://github.com/opencv/opencv_zoo) repository for client-side face processing.

---

## 1. YuNet (Face Detection & 5 Facial Landmarks)

- **Model Files**:
  - `face/yunet/face_detection_yunet_2023mar_int8.onnx` (Primary)
  - `face/yunet/face_detection_yunet_2023mar.onnx` (FP32 fallback)
- **Source**: [OpenCV Zoo - Face Detection YuNet](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)
